# Висновок:

Під час виконання лабораторної роботи було спроєктовано, реалізовано, протестовано та проаналізовано алгоритм сортування купою (HeapSort) мовою Python. Для вхідної послідовності варіанта №15 було виконано побудову максимальної купи та подальше сортування масиву за зростанням.
За допомогою трасування та графічної візуалізації досліджено обидві фази алгоритму: формування максимальної купи та послідовне переміщення найбільших елементів у кінець масиву. У результаті було отримано відсортовану послідовність [7, 19, 35, 48, 50, 51, 60, 80, 86].
На окремому прикладі продемонстровано нестійкість алгоритму HeapSort. Порівняльний аналіз із QuickSort показав, що для заданої послідовності HeapSort виконав 36 порівнянь та 69 присвоювань при обмінах, тоді як QuickSort – 47 порівнянь та 27 присвоювань. Також встановлено, що перевагою HeapSort є гарантована часова складність O(n log n) навіть у найгіршому випадку, на відміну від QuickSort, складність якого може досягати O(n²).
